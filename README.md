## 八、单向流量计费：到底怎么算？

这点容易被新手忽略，但直接影响你的实际成本。GoMami LAX Pulse 采用的是**单向出向流量计费模式**：

- **不计费的部分**：入向流量（Inbound），也就是从外部访问你服务器、向服务器上传文件、外部 API 调用你服务器的请求等等，这些都不消耗流量配额。
- **计费的部分**：出向流量（Outbound），也就是你的服务器主动对外发出的流量——网站向访客浏览器返回页面、服务器向外部推送数据、爬虫抓取后回传、视频/图片分发等等。

这种计费模式对不同业务的友好程度差异很大：

- **建站用户友好**：正常网站访问，访客请求的上行流量很小，服务器返回页面/图片的下行流量是大头——但等等，这里有个细节要厘清：从服务器角度看，返回给访客的内容属于"出向"，所以建站流量其实是会消耗配额的。只是相对而言，正常网站的访客量不会轻易把 1TB 月流量吃满，对小型站点来说 1TB/月绰绰有余。
- **下载/同步场景友好**：如果你是往服务器上同步数据（比如从国内 rsync 备份到洛杉矶），这部分上行流量不计费，相当划算。
- **流媒体/内容分发场景要注意**：视频、图片这类大文件对外分发属于出向流量，会快速消耗配额。如果你跑的是流媒体代理、视频分发业务，建议直接选 Air 以上的高流量套餐，否则很容易撞到流量上限被限速到 20 KB/s。

流量超限后限速到 20 KB/s 这条规则比较"硬"——没有按 GB 超量计费的弹性选项，超了就直接限速到几乎不可用，直到下个计费周期。所以选套餐时流量预估一定要留余量，宁可升一档也不要赌"应该用不完"。
